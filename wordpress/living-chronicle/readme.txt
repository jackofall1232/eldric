=== Eldric: The Living Chronicle ===
Contributors: eldric-contributors
Requires at least: 6.4
Requires PHP: 8.0
Stable tag: 0.1.0
License: MIT

An original top-down medieval storybook action-adventure. Explore Millhaven, investigate
Blackwater Bridge, fight monsters, uncover secrets, and write a persistent personal Chronicle.

== Installation ==

Activate the plugin and place `[living_chronicle]` on a page. No API key is required.
